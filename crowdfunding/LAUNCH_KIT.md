# Nexus launch kit — internal working document

## Positioning
**One-line description:** ZettaCore Nexus is an early-stage AI assistant project exploring continuity across conversations, user-controlled memory and permission-based tools.

**Audience:** AI/productivity enthusiasts, developers, privacy-minded users and early adopters interested in assistant tools.

**What we can honestly claim today:** a public interactive prototype, a minimal API foundation, experimental provider adapters and a public development roadmap.

**Do not claim yet:** real AI in the demo, persistent cloud memory, account system, active subscriptions, fully local desktop application, audited security, or a production-ready assistant.

## Short social post (English)
We're building ZettaCore Nexus, an early-stage AI assistant project exploring continuity between conversations, user-controlled memory and tools that require permission. The public demo is deliberately a prototype: simulated replies, no accounts and no payments yet. We're sharing the build openly and looking for thoughtful early feedback. Try the demo and follow the roadmap: https://zettacore-nexus.onrender.com/

## Product Hunt draft
**Name:** ZettaCore Nexus  
**Tagline:** An early-stage AI assistant project exploring memory and continuity  
**Description:** Nexus is an experimental project exploring a more continuous assistant experience with user-controlled memory and permission-based tools. The current public demo uses simulated replies and does not yet connect to a real model. We're sharing progress early to learn from the community before building accounts, cloud memory and subscriptions.  
**Topics to consider:** Artificial Intelligence, Productivity, Developer Tools (choose only those actually supported by the current product).  
**Launch assets:** current screenshots, short screen recording, honest feature list, roadmap, contact email, privacy notice and changelog.

## Community posting rules
- Read each community's self-promotion and launch rules before posting.
- Lead with the problem and the learning, not hype.
- Do not mass-post identical messages or ask for fake upvotes/reviews.
- Answer feedback and publish changes resulting from it.
- Never imply that supporters are buying equity or guaranteed financial returns.

## Crowdfunding video outline (60–90 seconds)
1. 0–10s: introduce ZettaCore and the idea of continuity and memory control.
2. 10–25s: screen-record the current prototype and explicitly label simulated responses.
3. 25–45s: show a simple roadmap: real model, secure accounts, persistent memory, quotas and privacy controls.
4. 45–65s: explain the budget with real, verified cost estimates and milestones.
5. 65–80s: describe possible supporter rewards, risks and how progress will be reported.
6. End: invite people to follow the project or share feedback; link to the live campaign only after it has been approved and launched.

## Metrics to watch
- Visits to the demo and source repository.
- Demo-to-feedback conversion.
- Beta testers who complete a short task list.
- Retention across repeated sessions.
- Model cost per active user after real AI is connected.
- Supporter conversion only after a legitimate campaign is live.
