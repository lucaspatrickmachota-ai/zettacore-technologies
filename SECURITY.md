# Security policy

## Scope

This repository contains the ZettaCore Technologies web presence and a personal portfolio. It is not a security-certified product, and the portfolio's abstract 3D visuals do not represent live threat telemetry.

## Reporting a potential vulnerability

Please do not publish sensitive exploit details or private information in a public issue.

For a suspected security issue, contact the repository owner through the contact links on the [portfolio](https://lucas-tech-portfolio.onrender.com/) and include:

- The affected page or file.
- Clear steps to reproduce the issue.
- The potential impact and any relevant screenshots or logs, with secrets and personal data removed.

Please only test systems you own or have explicit permission to assess. Do not submit real credentials, private data, or destructive proof-of-concept payloads.

## Response expectations

This is a personal learning project, so a response or fix is not guaranteed within a specific timeframe. Reports will be reviewed as time and capability allow.
