ZettaCore Nexus explores an AI assistant designed around continuity between conversations, memory the user can review and delete, and tools that require permission. We want to build an online edition and, eventually, a local edition.

Try the current demoView the source and roadmapContact the team
Transparency note: Nexus is currently a prototype. The public demo uses simulated replies; it is not connected to a real AI model and has no accounts, cloud memory, subscriptions or payment processing. This page does not accept donations or payments.

What exists today

  • Public interactive web prototype.
  • Initial Node.js API foundation.
  • Experimental provider adapters.
  • Public source repository and development notes.

What we want to build

  • Real model integration with usage limits.
  • Secure accounts and persistent memory controls.
  • Permission-based tools and clear privacy controls.
  • A free tier and optional paid subscriptions once costs are measured.
